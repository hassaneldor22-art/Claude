# 💣 القنبلة

القواعد: `../القنبلة.md`

```bash
cd game/bomb-game
npm install
npm start     # http://localhost:3000
npm test      # محاكاة لعبة كاملة + فحص بنك الأسئلة
```
متغيّرات اختبار: `FUSE_MIN_MS`, `FUSE_MAX_MS`, `WRONG_PENALTY_MS`, `GRACE_MS`, `COUNTDOWN_MS`, `BOOM_MS`.

نشر: Render عبر `render.yaml` بجذر المستودع (`rootDir: game/bomb-game`).
