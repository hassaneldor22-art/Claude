# 🎭 مين ورا القناع؟ — النموذج الأولي

لعبة دردشة سرية للأصدقاء (4–12 لاعب). القواعد الكاملة: `../مين-ورا-القناع.md`

## تشغيل محلي
```bash
cd game/mask-game
npm install
npm start        # http://localhost:3000
npm test         # محاكاة لعبة كاملة
```
للتجربة من الجوال على نفس الواي فاي: افتح `http://<عنوان-اللابتوب>:3000`.

## نشر على Render (مجاني)
1. أنشئ حساب على https://render.com واربطه بـGitHub.
2. New → Blueprint → اختر المستودع (يقرأ `render.yaml` تلقائياً).
3. بعد البناء بتاخد رابط مثل `https://mask-game.onrender.com`.
> الخطة المجانية بتنام بعد فترة بدون استخدام؛ أول فتحة ممكن تتأخر نص دقيقة.

## متغيّرات اختيارية
`ROUND_MS` (مدة الجولة، افتراضي 60000) — `RESULT_MS` (عرض النتيجة، افتراضي 10000).
